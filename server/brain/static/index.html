ADMINISTRATION DE PEPPER

Se connecter à Pepper

Préparez les visites, ajoutez des médias et réglez les services utilisés par Pepper.

Relancez le lanceur Pepper en mode setup sur l’ordinateur de l’antenne pour afficher votre jeton administrateur.

Modèle de conversation

Choisissez le service qui prépare les réponses de Pepper.

Transcription de la voix

Le son est transmis pendant que vous parlez. Choisissez OpenAI → GPT Live Transcribe pour le texte en continu, ou Whisper local pour conserver l’audio sur votre réseau.

En local, commencez par base sur une petite machine et vérifiez les noms propres. Les résultats intermédiaires locaux sont désactivés par défaut pour éviter de ralentir la réponse. Le mode OpenAI est facturé par le fournisseur et transmet l’audio hors du réseau ; son accès et sa latence sont à valider avec votre compte.

Recherche web et images

Sert à deux choses : trouver une image quand on lui en demande une, et chercher une réponse sur Internet quand Pepper ne la connaît pas. Serper donne accès aux résultats Google pour ces deux usages, avec une seule clé.

Recommandé : Google via Serper, pour les images, les informations et les visites. Créer un compte Serper, copier la clé API ci-dessous, puis enregistrer. Consultez votre compte Serper pour les crédits et les tarifs. Brave reste disponible ; Wikimedia reste une solution sans clé limitée aux images. Les licences des images restent à respecter.

Un e-mail ou un site permet à Wikimedia de vous joindre si ses requêtes sont limitées.

Utilise au plus une recherche payante ; un média déjà présent est prioritaire.
